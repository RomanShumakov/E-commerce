# E-commerce Project

Backend-приложение для управления каталогом товаров и категориями. Проект демонстрирует применение базовых принципов объектно-ориентированного программирования (ООП) на Python.

## Основной функционал

В проекте реализованы следующие классы:
- **Product**: Описывает сущность товара (название, описание, цена, количество).
- **Category**: Позволяет группировать товары и содержит логику подсчета количества категорий и уникальных продуктов.

## Работа с данными
- Проект поддерживает загрузку данных из формата JSON.
- Реализована автоматическая инициализация объектов классов `Category` и `Product` из внешних файлов, что позволяет легко масштабировать базу товаров.

## Структура данных
Данные в `products.json` представлены в виде списка категорий, где каждая категория содержит:
- `name`, `description`
- `products` (список объектов товара с его характеристиками).

## Технологии
- **Python 3.14+**
- **Poetry** — управление зависимостями и виртуальным окружением.
- **Pytest** — тестирование функционала.
- **Linters (Black, Flake8, Mypy, Isort)** — контроль качества кода.

## Установка и запуск

1. Склонируйте репозиторий.
2. Установите зависимости через Poetry:
   ```bash
   poetry install --no-root
   ```
