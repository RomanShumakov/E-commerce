# E-commerce Project

Backend-приложение для управления каталогом товаров и категориями. Проект демонстрирует применение базовых принципов объектно-ориентированного программирования (ООП) на Python: инкапсуляцию, наследование и полиморфизм.

## Основной функционал

В проекте реализована иерархия классов для управления товарами разных типов:
- **Product** — базовый класс описания товара (название, описание, цена, количество).
- **Smartphone** (наследник Product) — класс для смартфонов с дополнительными характеристиками (производительность, модель, объем памяти, цвет).
- **LawnGrass** (наследник Product) — класс для газонной травы (страна-производитель, срок прорастания, цвет).
- **Category** — класс для группировки товаров. Содержит логику подсчета количества категорий, уникальных продуктов, а также безопасный механизм добавления новых товаров.

## Ключевые возможности и ООП-паттерны

- **Инкапсуляция и валидация:** Доступ к цене товара (`price`) защищен с помощью геттера и сеттера. Изменение цены проходит валидацию — установить цену меньше или равную нулю невозможно.
- **Полиморфизм и перегрузка операторов:** 
  - Реализовано понятное строковое отображение объектов через метод `__str__`.
  - Реализовано сложение товаров через оператор `__add__`. При сложении двух товаров рассчитывается полная стоимость их остатков. Складывать можно только товары одного класса.
- **Строгая валидация типов при добавлении в категорию:** Метод добавления продукта в категорию проверяет, является ли добавляемый объект экземпляром класса `Product` или его наследников (`isinstance`). Попытка добавить некорректный тип данных вызывает ошибку `TypeError`.

## Работа с данными
- Проект поддерживает загрузку данных из формата JSON.
- Реализована автоматическая инициализация объектов классов из внешних файлов, что позволяет легко масштабировать базу товаров.

## Структура данных
Данные в products.json представлены в виде списка категорий, где каждая категория содержит:
- name, description
- products (список объектов товара с его характеристиками).

## Технологии
- Python 3.14+
- Poetry — управление зависимостями и виртуальным окружением.
- Pytest — тестирование функционала.
- Linters (Black, Flake8, Mypy, Isort) — контроль качества кода.
